
# DPPCC Cricket

Official cricket game project of
Dungshri Paschim Para Cricket Club.

## Game Engine
Godot Engine 4

## Current Development
- Main menu
- 3D cricket pitch
- Cricket wickets
- Ball delivery
- Batting timing system
- Basic scoreboard
- Practice match prototype

## Planned Features
- Realistic 3D players
- Batting and bowling
- Fielding and wicket keeping
- Stadium and crowd
- Tournament mode
- Multiplayer
- Android and Windows versions

## Project Structure
- project.godot
- scenes/main.tscn
- scripts/main.gd
